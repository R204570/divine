### NK Polycross LLP

- **Site:** nkpolycross.com
- **Type:** manufacturer - local rival (same Rupal-Bavla road)
- **Location:** 374/B, Village Zekda, Near Ramdev Food Factory, Rupal-Bavla Road, Bavla, Ahmedabad, Gujarat 382220
- **Founded:** 2017 per homepage; 2018 per About page snippet (inconsistent)
- **Products:** multilayer cross-laminated tarpaulin and covers, multilayer tarpaulin, rain poncho, rain suits, fumigation covers, pond liners, shipping bags / drum liners
- **GSM:** 70-300 GSM (films listed as 70, 90, 120, 150, 200, 250, 300; test table starts at 35 GSM); widths 4-9 ft
- **Ponchos:** True
- **Prices:** No prices on own site
- **Certifications:** ISO 9001:2015 (claimed), ISI licence CM/L-7200169712 (claimed), IS 14611:2016 (claimed)
- **Top-10 appearances:** 4

**Strengths**
- Owns the Rupal-Bavla query: IndiaMART profile #1, About page #3, TradeIndia profile #5
- Long multilayer product page with GSM-by-GSM test table (tensile, Elmendorf tear, dart impact, UV ageing) and a comparison table
- Shows ISO and ISI badges plus a Google review widget (4.3 stars, 21 reviews) with named reviewers
- Sells the same two product lines as Divine (tarpaulin + ponchos/rain suits); WhatsApp, call and mail buttons

**Weaknesses**
- Founding year conflicts (2017 vs 2018) and a 'more than 25 years' process claim
- Much of the product page wording, and an image file named 'supreme-silsack-shipping-bag-100.jpg', match Supreme Industries' XF page, so the content is not original
- No prices, no MOQ, no blog, Gmail address for sales

**How Divine Fabtech beats them**
- Publish Divine's own spec table per GSM (90/120/150/200, custom 70-200) with factory photos, so Divine has the original version of what NK borrows
- Show the Rs 20* poncho price and the MOQs (2 tons custom GSM tarpaulin, 20,000 pcs custom poncho) openly; NK hides both
- Close the review gap on Google Business Profile (Divine 3.7 stars/6 vs NK 4.3/21) by asking recent bulk buyers
- Make sure Divine's own IndiaMART and TradeIndia profiles name 'Rupal, Bavla' the way NK's do; those profiles are what rank #1 and #5
